# Repository agent instructions

## Engineering quality

Before reviewing code, implementing features, fixing defects, or refactoring, read [docs/agents/engineering-quality.md](docs/agents/engineering-quality.md). Assess code organization, architecture, lifecycle ownership, behavior, and tests together within the affected scope. Make routine engineering decisions and complete authorized repairs without waiting for the user to identify each structural problem.

Existing repository-specific review, delegation, validation, delivery, and device rules continue to apply.

## Agent skills

### Issue tracker

Issues and specs use GitHub Issues in `suminwell/CeenJs6-VSCode-Extension`. Before issue or spec operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triage or label changes, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before codebase exploration, read `docs/agents/domain.md`.
